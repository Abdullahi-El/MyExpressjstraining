# My Express.js Training

A simple Express.js project built with TypeScript to practice backend development.

## Features

- Express server
- TypeScript
- Static files
- npm scripts

## Installation

```bash
git clone https://github.com/yourusername/MyExpressjstraining.git
cd MyExpressjstraining
npm install
```

## Run

Development

```bash
npm run dev
```

Production

```bash
npm run build
npm start
```
